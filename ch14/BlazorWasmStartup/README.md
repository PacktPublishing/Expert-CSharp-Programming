# BlazorWasmStartup — Blazor WebAssembly Startup Essentials

This sample demonstrates startup patterns specific to **Blazor WebAssembly**:
- `WebAssemblyHostBuilder.CreateDefault(args)`
- DI registration and options binding
- Options validation at startup
- `HttpClient` base-address registration
- Structured startup logging

## Prerequisites
- .NET 10 SDK
- WebAssembly tools workload:

## Run

```bash
cd ch14/BlazorWasmStartup
dotnet run
```
